## Risks

- **密钥泄露** — 生产环境必须配置强密钥（`openssl rand -base64 32`）
- **XSS** — localStorage 存储，与 pomelo-orbit 一致
- **无状态限制** — JWT 一旦签发无法提前吊销
- **循环跳转** — 已分析排除：login 页面的 API 调用不会触发 401 拦截器
