# Continue your CLI work in the browser {#overview}

TermBridge brings Cloud CLI, Code XCLI, and Shell sessions running on your device into the browser. Commands still run on that device; you can continue work around projects, sessions, and frequently used commands.

## Start here {#get-started}

If TermBridge is not installed yet, read [Quick start](#quick-start) to download the official package, start the local workbench, and run your first CLI Session.

If you already use TermBridge, browse by task: create a CLI Session, return to an existing Session, manage a Workspace, or create a Shortcut for a frequent command.

## Common workflows {#common-workflows}

- **Start new work:** open a project directory and enter the original CLI command in a new Session.
- **Continue work:** open an in-progress Session from its Workspace.
- **Reuse a command:** save one frequent command as a Shortcut, then choose it while creating a new Session.

> Note: This documentation is for people who can already run Cloud CLI or Code XCLI in a device terminal. TermBridge does not install or sign in to those CLIs for you.
