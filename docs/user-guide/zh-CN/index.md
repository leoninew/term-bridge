# 在浏览器中继续你的 CLI 工作 {#overview}

TermBridge 把运行在你的设备上的 Cloud CLI、Code XCLI 和 Shell 会话带到浏览器中。命令仍在原来的设备上执行；你可以围绕项目、会话和常用命令继续工作。

## 从这里开始 {#get-started}

如果你还没有安装 TermBridge，请先阅读[快速开始](#quick-start)：下载正式制品、启动本地工作台，并运行第一个 CLI Session。

如果你已经在使用 TermBridge，可以按日常任务浏览：创建 CLI 会话、回到已有会话、管理 Workspace，或为常用命令建立 Shortcut。

## 最常用的工作流 {#common-workflows}

- **开始新任务**：进入项目目录，在新建 Session 中输入原始 CLI 命令。
- **继续已有任务**：在 Workspace 的 Session 列表中打开正在进行的会话。
- **复用命令**：将一条常用命令保存为 Shortcut，再在新建 Session 中选择它。

> 提示：本文档面向已经可以在设备终端中运行 Cloud CLI 或 Code XCLI 的用户。TermBridge 不会替你安装或登录这些 CLI。
