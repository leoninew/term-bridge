# 快捷方式多选、批量删除、导入导出
最后修改时间: 2026-07-19 08:46:16

Review status: Accepted

## Background

快捷方式管理页（`/shortcuts` 与云端 `/devices/:deviceId/shortcuts`）已支持单条创建、编辑、删除、启停、复制命令与拖拽排序。用户在迁移配置、备份复用或清理一批快捷方式时，仍需逐条操作，缺少批量删除与前端侧导入导出能力。

本期仅扩展前端交互；删除与创建仍复用现有 Agent shortcut API，不新增后端接口。

## Goal

1. 管理页增加**多选模式**入口按钮。进入多选后，点击卡片可切换选中/取消选中状态；再次点击同一卡片取消选中。
2. **至少有一张卡片被选中**时，显示：
   - **批量删除**按钮
   - **导出**按钮
3. 批量删除：点击后弹出小型确认模态；确认后按选中顺序**串行**调用现有 `deleteShortcut`，不并发。
4. 导出：点击后将被选中的快捷方式序列化为 JSON 数组，并触发浏览器下载。
5. **导入**按钮始终可见；点击后打开文件选择框，仅接受 JSON 文件；浏览器读取并校验后，按条目顺序**串行**调用现有 `createShortcut` 创建，不并发。
6. 允许快捷方式名称重复（与现状一致，导入时不因重名拦截）。
7. Local 与 Cloud 两条入口行为一致（共用 `ShortcutsPageShell`）。

## Non-goal

- 不新增后端批量删除、批量创建、导入导出 API。
- 不做服务端去重、名称唯一性约束变更。
- 不实现全选 / 反选。
- 不导出 `id` 与时间戳；导入不依赖客户端 id，一律走新建并由服务端生成 id 与时间。
- 不改变单条删除、单条编辑的既有语义；多选模式下禁用拖拽排序。
- 不实现导入预览、覆盖同 id、智能合并等策略；导入一律新建。
- 导入仅接受 JSON **数组**形态，不接受 `{ version, items }` 包装对象。

## User scenarios

1. 用户点击「多选」进入选择模式，点击若干卡片使其呈现选中态；再点已选卡片可取消。
2. 用户选中多条后点击「删除」，确认弹窗展示将删除的数量；确认后顺序删除，过程中有进行中状态。成功或失败停止后刷新列表，**清空选中集合，但保持多选模式**。
3. 用户选中多条后点击「导出」，浏览器下载一份 JSON 数组文件；导出完成后**退出多选模式并清空选中**。
4. 用户点击「导入」，选择本地 JSON 文件；校验通过后顺序创建；创建完成后刷新列表。部分失败时已创建项保留，后续停止。
5. 用户未进入多选或未选中任何卡片时，删除与导出按钮不可见；导入按钮仍可见。
6. 用户在筛选条件下进入多选：仅对当前可见卡片操作选中；批量删除/导出仅作用于当前选中集合。
7. 多选模式下，卡片「…」菜单仍可用（编辑 / 启停 / 删除单条）；单击卡片只负责切换选中，**不再支持双击编辑**。

## Acceptance

- [ ] 管理页工具区提供多选模式切换；多选模式下卡片可切换选中视觉状态，再点取消。
- [ ] 选中数 ≥ 1 时显示批量删除与导出；选中数为 0 时二者隐藏。
- [ ] 导入按钮始终可见，不依赖多选或选中状态。
- [ ] 批量删除经确认后，按选中顺序串行调用现有删除接口；禁止并发删除。
- [ ] 导出仅包含当前选中项，生成合法 JSON **数组**并触发浏览器下载。
- [ ] 导出字段仅含可复用业务字段：`name`、`command`、`description?`、`icon?`、`enabled?`、`tags?`；**不导出** `id`、`created_at`、`updated_at`、`last_used_at`。
- [ ] 导入读取 JSON 后做基本校验（必须是数组；每项含非空 name 与非空 command）；校验失败不发起创建请求；校验通过后按数组顺序串行 `createShortcut`。
- [ ] 导入不因名称重复而拒绝。
- [ ] 导入忽略源中的 `id` 与时间戳（若文件中误含则忽略），一律新建。
- [ ] 导入与批量删除均为 fail-fast：遇第一条失败即停止后续；toast 报告已成功数量与失败位置；已完成部分保留；随后刷新列表。
- [ ] 批量删除成功或中途失败后：清空选中集合，**保持多选模式**。
- [ ] 导出成功后：退出多选模式并清空选中集合。
- [ ] 多选模式下禁用拖拽排序；退出多选后（且无筛选时）恢复拖拽。
- [ ] 移除卡片双击编辑；多选时「…」菜单仍可使用。
- [ ] 操作过程中有 loading/disabled 防重复提交；i18n 中英文齐全。
- [ ] Local `/shortcuts` 与 Cloud `/devices/:deviceId/shortcuts` 行为一致。
- [ ] 不破坏现有单条 CRUD、筛选、标签过滤与（非多选时的）拖拽排序。

## Open questions

无。用户已确认全部决策点。

## Decisions

- **纯前端导入导出**，复用现有 `createShortcut` / `deleteShortcut`。
- **串行**执行批量删除与导入创建，不并发。
- **允许名称重复**。
- 导出字段：`name`、`command`、`description?`、`icon?`、`enabled?`、`tags?`；**不导出 id 与时间戳**。
- 导入忽略 id 与时间戳，一律 `create`（服务端生成 id 与时间）。
- 导入 JSON 形态：**仅 JSON 数组** `ShortcutExportItem[]`。
- 失败策略：fail-fast（遇错停止），已完成部分保留，toast 说明进度。
- 导出文件名：`termbridge-shortcuts-YYYYMMDD-HHmmss.json`。
- 多选模式下**禁用拖拽**。
- 批量删除完成后**保持多选模式**并清空选中；导出成功后**退出多选模式**并清空选中。
- **移除双击编辑**；多选时「…」菜单仍可用。
- 批量删除确认弹窗贴近现有删除对话框风格，文案强调数量与不可撤销。

## Risk

- 大量条目串行导入/删除耗时长，UI 需明确进行中与不可重复点击。
- 用户导出含敏感命令（密钥、token）时，下载文件落在本地磁盘；产品侧不加密，仅用户自担。
- 导入校验过松可能提交空命令；过严可能与导出格式不兼容——校验规则与导出 schema 对称。
- 多选与卡片菜单、拖拽手势可能冲突；多选下单击只负责选中，拖拽禁用，菜单通过 `data-no-drag` / stopPropagation 保留。
- Cloud 路径下串行多次请求经隧道，延迟更明显；需可接受的进度提示。
