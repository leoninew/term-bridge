# 填充型次要按钮统一

最后修改时间: 2026-07-15 10:02:09

Review status: Accepted

## Flow mode / Stage

轻量模式 / light；需求 / Requirement 已接受，用户已明确要求开始实现 / Implementation。

## Background

当前前端的 `.button-secondary` 和部分局部次要操作以中性描边或透明样式呈现。不同页面对取消、返回和辅助导航等主要次要操作的视觉强调不一致，且 outlined 样式与当前希望采用的弱强调填充按钮方向不一致。

## Goal

1. 将共享 `.button-secondary` 统一为无描边、非透明的弱强调填充按钮。
2. 将各页面承载主要次要动作的现有 `.button-secondary` 使用点统一继承该共享样式。
3. 保持主按钮、文字链接、图标工具按钮以及身份提供商选择器等独立语义控件的视觉和交互边界。

## Non-goal

1. 不改变任何按钮的文案、路由、提交、取消、删除、认证或数据请求行为。
2. 不将主按钮改为次要按钮，也不重设计主按钮颜色体系。
3. 不机械修改无描边文字链接、悬浮工具图标或身份提供商登录/注册选择器。
4. 不混入已暂存的 `/shortcuts` 卡片信息层级改动。

## User scenarios

1. 用户在创建、编辑、删除等对话框中看到取消操作，视觉上为弱强调填充按钮而非描边或透明按钮。
2. 用户在快捷方式页使用“返回工作区”等次要导航操作时，获得与对话框取消操作一致的次要按钮视觉。
3. 用户仍可通过颜色和填充层级区分主提交动作与次要动作，原有键盘焦点、禁用状态和点击行为不变。

## Acceptance

- [ ] `.button-secondary` 静止、hover、focus-visible 和 disabled 状态不再呈现描边或透明背景。
- [ ] 已使用 `.button-secondary` 的主要次要动作无需逐页重写即可获得统一样式。
- [ ] 按钮在深色和浅色主题中仍具备可辨识的背景、文字和焦点状态。
- [ ] 主按钮、文字链接、图标工具按钮、身份提供商选择器及其行为不发生无关变更。
- [ ] 不影响既有表单提交、取消、抽屉关闭、页面返回和键盘交互。
- [ ] 仅暂存本功能实际涉及的样式、必要组件和 Requirement 文档，不纳入既有 `/shortcuts` 卡片或云认证改动。

## Open questions

暂无需要用户确认的未决事项。身份提供商选择器保留独立语义，未纳入本轮统一次要按钮样式。

## Decisions

- 以全局 `.button-secondary` 作为唯一共享样式入口，减少逐页重复的中性描边定义。
- 次要按钮使用已有语义颜色 token 的弱强调填充，而非透明或边框强调；hover/focus 使用同一填充层级的状态 token。
- 已通过 `.button-secondary` 表达次要语义的取消、返回和辅助页面动作保持类名不变，仅继承全局视觉更新。
- 图标关闭控件保留其局部透明样式，因为其属于工具型关闭 affordance，不是页面主要次要动作。

## Risk

- `.button` 的基础边框规则会影响所有按钮变体；实现必须为 `.button-secondary` 显式覆盖边框，不能移除 `.button` 的全局基础边框，否则会影响主按钮和未纳入范围的控件。
- 弱强调填充的深浅需要同时覆盖 light/dark theme，避免在禁用、hover 和键盘焦点下与页面表面混淆。
- 个别页面可能叠加 `bg-[var(--color-surface-raised)]` 等 utility；共享样式应保持足够明确，必要时仅清理与新统一样式直接冲突的局部覆盖。
