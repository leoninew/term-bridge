# Home 页 Agent 模式前端界面需求
最后修改时间: 2026-07-08 15:35:00

Flow mode: light / 轻量模式
Stage: Requirement / 需求
Review status: Accepted

## Background

当前需要先从 Home 页的 agent 模式界面开始做一轮纯前端改版。项目约束为使用现有前端技术栈：reka-ui、Tailwind v4、@lucide/vue，不引入其他前端组件库。reka-ui 使用方式以后续实现时参考 `docs/reka-llms.txt`。

本轮只处理 Home 页 agent 模式。cloud 模式会另行设计，但当前界面需要为 cloud 模式保留位置或结构边界，避免把 agent/cloud 两种模式混在一起。

## Goal

1. 在 Home 页 agent 模式界面添加顶部工具栏。
2. 顶部工具栏左上展示 LOGO，LOGO 当前使用 base64 占位。
3. 顶部工具栏右上展示远程连接状态，并复用已有多语言切换和主题切换按钮；连接状态、语言与主题均为 icon button，icon 按当前状态动态切换，语言/主题单击即切换，不展示 dropdown。连接状态只展示动态 icon，不承载模式切换入口。
4. 页面主体居中展示上下结构的两个卡片。
5. 上方卡片"本机工作台"展示本机信息，包括：
   - 本机设备；
   - 当前用户；
   - 本项目版本。
6. 上方卡片 header 右侧保留"连接云端"按钮用于已有 OAuth2 认证逻辑，未连接时该按钮使用 Plug icon；已连接时同一按钮切换为"断开云端"并使用 Unplug icon，但断开接口待实现，本轮仅展示禁用状态。同时提供"切换到 Cloud 模式"入口，其中切换入口仅在已连接云端时可用。顶部工具栏右上仅保留连接状态 icon（纯展示）。
7. 下方卡片通过已有工作区接口展示真实工作区列表项，不使用 TODO 工作区占位。
8. 工作区列表项右侧展示"进入"含义的 icon，但本轮不添加点击交互。
9. 下方卡片 header 右侧放置"打开工作区"按钮（FolderOpen icon），点击跳转到 `/agent/sessions` 已有路由。
10. 需要后端接口支持的信息先用 TODO 占位，避免在纯前端阶段发明接口契约。
11. Home 页自身不再自动跳转到 agent 或 cloud 的其他页面；后续通过明确的页面入口承载跳转。
12. 移除右下角全局 agent/cloud 模式切换元素；agent 模式下切换到 cloud 模式入口放在"本机工作台"卡片右上角，且仅在已连接云端时可用。
13. 移除工作区列表下方的 cloud 模式预留说明文案。

## Non-goal

1. 不实现 cloud 模式具体界面，仅为后续 cloud 模式设计保留位置或分支结构。
2. 不新增后端接口、不修改后端接口契约。
3. 不新增前端组件库，不引入 reka-ui、Tailwind v4、@lucide/vue 之外的组件依赖。
4. 不为工作区列表的进入 icon 添加交互、路由跳转或状态变更。
5. 不把 TODO 占位伪装成真实接口数据。
6. 不保留 Home 页访问时自动重定向到 agent dashboard、cloud dashboard 或登录页的行为。
7. 本轮不为"打开工作区"按钮造新路由，跳转到已有的 `/agent/sessions`。

## User scenarios

1. 用户进入 Home 页并处于 agent 模式时，可以看到清晰的顶部工具栏、LOGO、远程连接状态 icon button（已连接 hover 显示连接时间）、多语言 icon button 和主题 icon button；这些 icon 会按当前状态动态切换，语言/主题可通过单击按钮直接切换。
2. 用户可以在"本机工作台"卡片看到本机设备、当前用户、项目版本三列信息；header 右侧未连接时展示 Plug + "连接云端"用于 OAuth2 认证，已连接时切为 Unplug + "断开云端"禁用态（接口待实现），并展示"切换到 Cloud 模式"入口，切换入口只有已连接云端时可用。
3. 用户可以在页面主体下方看到通过已有接口加载的工作区列表项，以及每个工作区列表项右侧的进入 icon；下方卡片 header 右侧有"打开工作区"按钮，可跳转到 `/agent/sessions`。
4. 用户能从页面结构上理解 agent 模式是当前已设计区域，cloud 模式仍保留为后续设计空间。
5. 用户访问 Home 页时停留在 Home 页，不被自动带到 agent 或 cloud 的其他页面。

## Acceptance

1. Home 页 agent 模式存在顶部工具栏，左上为 base64 占位 LOGO，右上为远程连接状态展示，并复用已有多语言切换和主题切换按钮；连接状态、语言和主题都使用 icon button，icon 按状态动态切换，语言/主题单击即切换，不展示 dropdown；连接状态已连接时 hover 显示连接时间，右上角不承载 cloud 模式切换入口。
2. 顶部工具栏按钮无大边框。
3. agent 模式主体区域居中，包含上下两个卡片。
4. 上方卡片标题为"本机工作台"，header 右侧未连接时展示 Plug + "连接云端"用于 OAuth2 认证；已连接时该按钮切为 Unplug + "断开云端"禁用态（断开接口待实现）；同时提供"切换到 Cloud 模式"入口，且只有已连接云端时可用。卡片内容展示本机设备、当前用户、项目版本三列；缺少后端数据时使用明确 TODO 占位。
5. 下方区域通过已有工作区接口展示真实工作区列表项；列表项右侧存在进入含义 icon，但没有点击交互；卡片 header 右侧有"打开工作区"按钮，跳转到 `/agent/sessions`。
6. cloud 模式不在本轮实现具体 UI，但代码结构或页面布局中保留后续设计位置。
7. 实现不引入新的前端组件库。
8. 实现阶段需要先确认当前 Home 页、agent/cloud 模式切换和现有组件风格，再修改代码。
9. 访问 Home 页不会自动跳转到 agent 或 cloud 的其他页面；后续跳转只通过明确入口触发。
10. 工作区列表卡片下方不展示 cloud 模式预留说明文案。

## Open questions

暂无必须阻塞实现的问题。以下信息在实现阶段按 TODO 占位处理，后续可接入真实接口：

1. 当前用户来自哪个后端接口或运行时上下文。
2. 本项目版本来自 package 元数据、后端接口还是构建注入。
3. 远程连接状态的真实状态源。
4. 工作区列表的真实数据结构、排序和空状态规则。

## Decisions

1. 本轮采用 light / 轻量模式，仅创建 Requirement / 需求，用户接受后再进入 Implementation / 实现。
2. 本轮是纯前端项目，不新增后端接口。
3. 组件库边界固定为 reka-ui + Tailwind v4 + @lucide/vue，不引入其他前端组件。
4. 所有需要后端信息的位置先显式 TODO 占位。
5. 工作区列表右侧 icon 只展示，不绑定交互。
6. 顶部工具栏右上远程连接状态、多语言切换和主题切换都使用 icon button；icon 按状态动态切换。语言和主题复用已有实现，不重新设计状态管理，交互为单击按钮直接切换，不使用 dropdown。连接状态触发器纯展示、无 dropdown，不承载模式切换入口。
7. Home 页作为独立入口页保留，不再由路由自动重定向到 agent 或 cloud 其他页面；后续跳转入口在页面内设计。
8. 卡片标题改为"本机工作台"，header 右侧放连接入口；卡片内容为三列（本机设备/用户/版本），不展示连接时间。
9. 右上角连接状态 icon 已连接为绿色 Cloud，未连接为红色 CloudOff。
10. "工作区列表"卡片 header 右侧的"打开工作区"按钮使用 FolderOpen icon，点击跳转到已有的 `/agent/sessions` 路由。

## Risk

1. 如果当前 Home 页已有 agent/cloud 模式逻辑，修改时需要避免破坏 cloud 模式现有入口或状态管理。
2. TODO 占位需要在 UI 上保持可识别，避免用户误以为已经接入真实数据。
3. base64 LOGO 只是临时占位，后续替换真实品牌资源时可能需要调整尺寸和对齐。
4. 远程连接状态如果没有真实数据源，本轮只能展示占位语义，不能验证真实连接状态。
